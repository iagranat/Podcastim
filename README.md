# פודקאסטים לילדים (Podcastim App) 🎧🎈

אפליקציית מובייל מודרנית ואינטואיטיבית לאתר הפודקאסטים הישראלי **[podcastim.org.il](https://podcastim.org.il/)**, עם דגש מיוחד על חוויית משתמש ייעודית, עליזה ונגישה לילדים (מצב ילדים), לצד גישה לקטלוג המלא של כל הפודקאסטים המובילים בישראל (מצב הורים / קטלוג מלא).

---

## ✨ תכונות מרכזיות (Features)

### 🎈 מצב ילדים ייעודי (Kids Mode - ברירת מחדל)
* **עיצוב מותאם לילדים**: כרטיסים גדולים עם פינות מעוגלות רכות (24px), צבעים חמים ועליזים, צללים עדינים ואייקונים ברורים.
* **התאמה מלאה לעברית (RTL)**: טיפוגרפיה ברורה וקריאה, מספור פרקים בעברית וניווט טבעי מימין לשמאל.
* **נושאי עניין ויזואליים**: סינון בלחיצה אחת על בועות נושא (🌙 סיפורי לילה טוב, 🦁 חיות וטבע, 🚀 חלל וכוכבים, 🔍 הרפתקאות ובילוש, 🧪 מדע וסקרנות, 😂 מצחיק וטריוויה).
* **נעילת הורים (Parent Gate)**: אתגר חשבון מתחלף (כפל/חיבור) שמונע מילדים לעבור למצב קטלוג מלא או לשנות הגדרות ללא רשות הורה.

### 🎙️ סנכרון חי ודינמי מול האתר (Live Dynamic Sync)
* **חיבור ישיר ל-WordPress REST API**: האפליקציה מתחברת בזמן אמת ל-`https://podcastim.org.il/wp-json/wp/v2/`.
* **כל פרק חדש שנוסף לאתר מופיע מיד באפליקציה**: מנגנון משיכה לרענון (Pull-to-Refresh) ששואב את רשימות הפרקים העדכניות ביותר.
* **חילוץ קישורי שמע ישירים (Direct MP3 Extraction)**: חילוץ אוטומטי של מקורות השמע מתוך נתוני הנגן של האתר (`data-ppsdata`), המאפשר הזרמת שמע ישירה ללא תלות בדפדפן.

### 🎵 נגן שמע מתקדם (Advanced Audio Player)
* **נגן מיני צף (Persistent Mini Player)**: מלווה את המשתמש בכל מסכי האפליקציה עם קו התקדמות וכפתורי השמעה/השהיה מהירים.
* **נגן מלא (Full Player Modal)**: עטיפה גדולה באיכות גבוהה, סרגל גרירה (Scrubber), דילוג 15 שניות קדימה ואחורה, מעבר לפרק הבא/הקודם.
* **טיימר שינה (Sleep Timer)**: מושלם להאזנה לפני השינה! כיבוי אוטומטי לאחר 15, 30, 45, 60 דקות או בסיום הפרק הנוכחי.
* **שליטה במהירות ההשמעה**: 0.8x (מתאים לקטנטנים), 1.0x, 1.2x, 1.5x.
* **השמעה ברקע (Background Playback)**: הפודקאסט ממשיך להתנגן גם כשהמסך כבוי או בעת מעבר לאפליקציה אחרת באמצעות מודול השמע הרשמי והעדכני `expo-audio`.
* **דירוגי גולשים באתר (Live User Ratings)**: חילוץ והצגת ממוצעי דירוג וכמות מדרגים ישירות מהאתר (`⭐ 4.8 (52)`) הן בכרטיסי הפודקאסט והן במסך הפודקאסט המלא עם חיווי כוכבים מותאם עברית (RTL).

### ⭐ מועדפים והיסטוריית האזנה
* **סימון בלב (Favorites)**: שמירה מקומית מהירה של כל הפודקאסטים האהובים.
* **היסטוריה (Recently Played)**: מעקב אוטומטי אחרי 30 הפרקים האחרונים שהושמעו.
* שמירה מאובטחת במכשיר באמצעות `@react-native-async-storage/async-storage`.

## 🚀 הוראות הרצה ובדיקה (Getting Started)

### 1. הפעלת שרת הפיתוח (Expo Dev Server)
להרצת האפליקציה:
```bash
npx expo start
```
או באמצעות npm:
```bash
npm start
```

### 2. בדיקה על מכשיר אנדרואיד פיזי (Android Device)
1. הורידו את אפליקציית **Expo Go** מחנות Google Play.
2. ודאו שהמחשב והסלולרי מחוברים לאותה רשת Wi-Fi.
3. סרקו את קוד ה-QR שמופיע בטרמינל. האפליקציה תיטען מיד במכשירכם.

### 3. בדיקה בדפדפן (Web Preview)
לבדיקה ישירה בדפדפן המחשב:
```bash
npm run web
```

### 4. בניית קובץ APK אוטומטית (Automated GitHub Actions CI/CD)
בפרויקט מוגדר תהליך CI/CD אוטומטי מלא ב-**GitHub Actions** (`.github/workflows/build-apk.yml`):
- **בכל Commit / Push לענף הראשי (`main`)**: GitHub Actions מבצע בנייה מלאה (`expo prebuild` ו-Gradle) ומייצר קובצי APK מוכנים להתקנה מיידית על כל מכשיר אנדרואיד.
- **הורדת ה-APK**: נכנסים ללשונית **Actions** במאגר ה-GitHub שלכם, בוחרים את הריצה האחרונה, ומורידים את הקובץ תחת **Artifacts** (`Podcastim-Android-APK`).
- **גרסאות רשמיות (Releases)**: ביצוע תיוג גרסה (Tag, למשל `v1.0.0`) מפרסם אוטומטית Release רשמי עם קובץ ה-APK להורדה ישירה.

בנוסף, ניתן לבנות ישירות בענן דרך EAS Build:
```bash
npx eas-cli build -p android --profile preview
```
